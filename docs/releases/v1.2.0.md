# Trace v1.2.0 / 词迹 v1.2.0

Trace 1.2.0 adds Equation Trace, a third fully offline tool that finds arithmetic expressions from a selected length, target result, and gray, yellow, and green clues.

## Highlights

### Equation Trace

- Choose an expression length from 3 to 8 characters. The length excludes `= result`.
- Enter a whole-number target result from −9999 to 9999.
- Use the digits `0–9` and the operators `+`, `−`, `×`, and `÷`.
- Combine up to six previous guesses.
- Tap each character tile to cycle through gray, yellow, and green.
- Select a candidate to copy the complete equation.

### Exact arithmetic and clue handling

- Uses standard precedence: multiplication and division before addition and subtraction.
- Evaluates same-level operations from left to right.
- Uses exact rational arithmetic instead of floating-point result comparisons.
- Rejects multi-digit numbers with leading zeros and every division by zero.
- Applies Wordle-style two-pass scoring to repeated digits and operators.
- Calculates the exact number of matching candidates and retains up to 3,000 for display.

### Shared app behavior

- Equation Trace supports English, Simplified Chinese, and Traditional Chinese.
- It uses the System, Light, or Dark appearance selected in Settings.
- The Android app can resume Equation Trace as the last-used tool.
- GitHub Pages now publishes all three tools.
- A standalone HTML page, bilingual README, short guide, and ZIP package are included.

### Idiom pronunciation audit

- Reviewed all 29,474 bundled idiom entries against multiple dictionaries.
- Corrected 1,049 idioms, covering 1,254 changed syllable positions and 14 tone-mark formatting-only fixes.
- Applied the same corrected data to the standalone page, offline ZIP, Android assets, build output, and APK.
- See [`PINYIN_CORRECTIONS.md`](../../idiom-trace/PINYIN_CORRECTIONS.md) for the complete before-and-after list.

## Installation

- Requires Android 6.0 (API 23) or later.
- Can update Trace 1.1.3 directly without uninstalling it.
- Existing language, appearance, text-size, motion, haptic, screen, and resume preferences are preserved.
- No network or additional system permission was added.

词迹 1.2.0 新增第三款完全离线工具“猜算式”，可按用户选择的字符长度、计算结果和灰黄绿线索寻找四则运算表达式。

## 主要更新

### 猜算式

- 可选择 3～8 个字符的算式长度，长度不包含“`= 结果`”。
- 可输入 −9999 到 9999 的整数计算结果。
- 支持数字 `0～9` 和算子 `+`、`−`、`×`、`÷`。
- 最多可合并六次历史猜测。
- 点击每个字符方块可在灰、黄、绿三种颜色之间切换。
- 点击候选结果即可复制完整算式。

### 精确计算与线索处理

- 遵循标准运算优先级：先乘除，后加减。
- 同级运算从左到右计算。
- 使用精确分数计算，不依赖浮点数近似比较结果。
- 排除多位数前导零和所有除以零的情况。
- 对重复数字和算子使用 Wordle 类游戏的两轮颜色判定。
- 精确统计符合条件的候选总数，并最多保留 3,000 条用于显示。

### 应用统一行为

- 猜算式支持英语、简体中文和繁体中文。
- 使用设置中选择的跟随系统、浅色或深色外观。
- Android 应用可把猜算式作为上次使用的工具继续打开。
- GitHub Pages 现在会发布全部三款工具。
- 提供独立 HTML 网页、中英双语 README、简明指南和 ZIP 压缩包。

### 成语拼音审校

- 对照多部词典复核全部 29,474 条内置成语。
- 修正 1,049 条成语，涉及 1,254 个音节位置，并包含 14 条仅修正声调符号格式的记录。
- 同一份修正数据已同步到独立网页、离线 ZIP、Android 资源、build 产物和 APK。
- 完整修改前后对照表见 [`PINYIN_CORRECTIONS.md`](../../idiom-trace/PINYIN_CORRECTIONS.md)。

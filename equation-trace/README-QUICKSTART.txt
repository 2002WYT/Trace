EQUATION TRACE · OFFLINE EDITION

HOW TO USE
1. Open "equation-trace-offline.html" in Chrome, Edge, Firefox, Safari, or another modern browser.
2. Choose an expression length from 3 to 8. The length covers only the expression itself.
3. Enter a whole-number target result from -9999 to 9999.
4. Type a known character directly into any tile. Use +, -, *, and / for operators.
5. A clue row may be incomplete; empty tile positions are ignored.
6. New characters start gray. Tap a filled tile to cycle through gray, yellow, and green.
7. Add up to six clue rows, then select "Find equations".
8. Select a result to copy the expression only.

NOTES
- Standard precedence is used: multiplication and division before addition and subtraction.
- Leading zeros and division by zero are rejected.
- Repeated digits and operators use Wordle-style two-pass color scoring.
- The interface supports English, Simplified Chinese, and Traditional Chinese.
- The complete interface and solver are embedded in the HTML file.
- All generation and filtering happens locally. Nothing is uploaded.

猜算式 · 完全离线版

使用方法
1. 使用 Chrome、Edge、Firefox、Safari 或其他现代浏览器打开“equation-trace-offline.html”。
2. 选择 3～8 个字符的算式长度；长度只计算算式本身。
3. 输入 −9999 到 9999 的整数结果。
4. 在任意方块中直接输入已知字符；算子使用 +、-、*、/。
5. 线索不必填满，空白方块会被忽略。
6. 新字符默认为灰色；点击已填写的方块可在灰、黄、绿之间循环。
7. 最多可添加六行线索，然后点击“查找算式”。
8. 点击结果时只会复制算式本身。

说明
- 使用标准四则运算优先级：先乘除，后加减。
- 不允许前导零或除以零。
- 重复数字和算子使用 Wordle 类游戏的两轮颜色判定。
- 界面支持英语、简体中文和繁体中文。
- 完整界面和筛选程序均内置在 HTML 文件中。
- 所有生成和筛选都在本地完成，不会上传任何输入。

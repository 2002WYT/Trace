# Trace v1.0.2 / 词迹 v1.0.2

This was the first unified release combining Idiom Trace, Word Trace, and the Android client.

## What's new

- Added the top-right home menu and Settings page.
- Added Standard, Large, and Largest text sizes.
- Added an option to keep the screen on while solving.
- Saved settings locally between launches.
- Added an About page with version, author `2002WYT`, and project links.
- Retained the portrait-layout fixes and high-resolution launcher assets from v1.0.1.

## Installation

1. Download `Trace-v1.0.2.apk`.
2. Open it on an Android phone.
3. If prompted, allow installation from the current app.
4. If v1.0.0 or v1.0.1 is installed, choose **Update** without uninstalling it.

## Compatibility and privacy

- Android 6.0 (API 23) or later.
- Fully offline operation.
- No network permission.
- No uploaded clues or usage records.

## 本版本更新

- 新增应用首页右上角菜单和“设置”页面。

- 支持解题时保持屏幕常亮。

- 保留 v1.0.1 的手机竖屏布局修复和高清启动图。

## 安装方法

1. 下载 `Trace-v1.0.2.apk`。
2. 在 Android 手机上打开 APK。
3. 首次安装时，根据系统提示允许当前应用“安装未知应用”。
4. 如果已经安装 v1.0.0 或 v1.0.1，直接选择“更新”，无需卸载旧版。

## 兼容性与隐私

- 最低支持 Android 6.0（API 23）。
- 应用完全离线运行。
- 不申请网络权限。

# 词迹 Trace v1.0.2

这是 **Idiom Trace**、**Word Trace** 与 Android 客户端合并后的首个统一发布版本。

## 本版本更新

- 新增应用首页右上角菜单。
- 新增“设置”页面。
- 支持标准、较大、特大三档文字大小。
- 支持解题时保持屏幕常亮。
- 设置会在设备本地保存。
- 新增“关于”页面，显示版本和作者 `2002WYT`。
- 增加 Idiom-Trace 与 Word-Trace 的 GitHub 链接。
- 保留 v1.0.1 的手机竖屏布局修复和高清启动图。

## 安装方法

1. 下载下方的 `Trace-v1.0.2.apk`。
2. 在 Android 手机上打开 APK。
3. 首次安装时，根据系统提示允许“安装未知应用”。
4. 如果已经安装 v1.0.0 或 v1.0.1，直接选择“更新”，不需要卸载旧版本。

## 兼容性与隐私

- 最低支持 Android 6.0（API 23）。
- 应用完全离线运行。
- 不申请网络权限。
- 不上传任何猜词内容或使用记录。

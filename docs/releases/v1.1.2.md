# Trace v1.1.2 / 词迹 v1.1.2

This release reorganized the Android home screen, navigation, and settings and improved portrait-phone usability.

## Highlights

### Compact home screen

- Both tools fit in a typical phone viewport.
- Repeated offline, account, and APK explanations were removed.
- Headings, tool entries, and menus received a clearer hierarchy.
- Each tool opens directly in its working area.

### More settings

- Added transitions, haptic feedback, and resume-last-tool options.
- Retained text-size and keep-screen-on settings.
- Added one-tap restoration of defaults.

### Navigation and system bars

- Added top-left back controls throughout the app.
- Reserved native space for the status and navigation bars.
- Replaced custom fullscreen handling with a more compatible native window.
- Kept the Android system Back action working as expected.

## Installation

- Requires Android 6.0 or later.
- Can update v1.0.2 directly without uninstalling it.
- Keeps the same application ID and signing identity, preserving existing settings.
- Adds no network or other system permission.

本版本重新整理了 Android 端的首页、导航和设置，并改善手机竖屏下的使用体验。

## 主要更新

### 紧凑首页

- 两个工具入口可直接显示在普通手机竖屏首屏内。
- 删除重复的离线、账号和 APK 说明。
- 重新整理标题、工具入口和菜单的视觉层级。
- 两个工具打开后直接进入操作区域。

### 更完整的设置

- 新增过渡动画、触感反馈和“启动时继续上次工具”选项。
- 保留文字大小和解题时保持屏幕常亮设置。
- 支持一键恢复默认设置。

### 导航与系统栏

- 所有主要界面增加左上角返回按钮。
- 顶部状态栏和底部导航栏使用系统保留的独立空间。
- 用兼容性更好的原生窗口替代自定义全屏处理。
- 手机系统返回键仍可正常使用。

## 安装说明

- 最低支持 Android 6.0。
- 可直接覆盖安装 v1.0.2，无需卸载。
- 应用包名和签名保持不变，原有设置会继续保留。
- 未新增网络或其他系统权限。

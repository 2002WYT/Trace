WORD TRACE · OFFLINE EDITION

HOW TO USE
1. Double-click "word-trace-offline-en.html".
2. Open it with Chrome, Edge, Firefox, Safari, or another modern browser.
3. Choose the word length and one or more exam dictionaries.
4. Type a complete guessed word or click a tile to enter one letter.
5. New letters start gray. Click a filled tile to cycle through gray, yellow, and green.
6. Click "Find remaining words" to view matching candidates.

NOTES
- The interface supports English, Simplified Chinese, and Traditional Chinese.
- The standalone file follows the browser language and system light or dark appearance.
- No installation or internet connection is required.
- The dictionary, interface, and program are embedded in the HTML file.
- All filtering happens locally. Nothing you enter is uploaded.

WORD TRACE · 完全离线版

使用方法
1. 双击打开“word-trace-offline-en.html”。
2. 使用 Chrome、Edge、Firefox、Safari 或其他现代浏览器打开。
3. 选择单词长度和至少一套考试词表。
4. 输入完整的已猜单词，或点击字母格逐个输入。
5. 新字母默认为灰色；点击已填写的格子可在灰、黄、绿之间循环。
6. 点击“查找剩余单词”查看所有符合条件的候选词。

说明
- 界面支持英语、简体中文和繁体中文。
- 独立文件会跟随浏览器语言与系统深浅色外观。
- 不需要安装或互联网连接。
- 完整词表、界面和程序均内置在 HTML 文件中。
- 所有筛选都在本地完成，不会上传任何输入。

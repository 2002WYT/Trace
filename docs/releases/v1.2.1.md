# Trace v1.2.1 / 词迹 v1.2.1

Trace 1.2.1 refines Equation Trace input and output so clues can be entered more flexibly and copied results match the expression format used by the game.

## Highlights

### Flexible clue entry

- Type a character directly into any individual clue tile.
- Leave unknown positions empty and search without completing the row.
- Empty tile positions are ignored while every filled gray, yellow, and green clue is still applied.
- Full-row entry remains available for complete previous guesses.

### Expression format

- Multiplication and division now use `*` and `/` throughout generation, display, filtering, and copied text.
- Candidate results contain only the expression.
- Copying a candidate no longer appends an equals sign or the target answer.

### Compatibility and privacy

- Requires Android 6.0 (API 23) or later.
- Can update Trace 1.2.0 directly without uninstalling it.
- Existing language, appearance, text-size, motion, haptic, screen, and resume preferences are preserved.
- No network or additional system permission was added.
- Equation generation and clue filtering remain fully offline on the device.

词迹 1.2.1 改进了“猜算式”的线索输入与结果输出方式，让不完整线索也能参与筛选，并使复制内容与游戏使用的算式格式保持一致。

## 主要更新

### 灵活录入线索

- 可直接在任意单个线索方块中输入字符。
- 未知位置可以留空，无需填满整行即可查找。
- 筛选时会忽略空白方块，同时继续应用所有已填写的灰、黄、绿线索。
- 仍然可以通过整行输入框录入完整的历史猜测。

### 算式格式

- 生成、显示、筛选和复制时，乘除运算统一使用 `*` 和 `/`。
- 候选结果只显示算式本身。
- 复制候选时不再附加等号与目标答案。

### 兼容性与隐私

- 最低支持 Android 6.0（API 23）。
- 可直接覆盖安装词迹 1.2.0，无需卸载。
- 原有语言、外观、文字大小、动画、触感、常亮和继续上次工具设置都会保留。
- 未新增网络或其他系统权限。
- 算式生成和线索筛选仍然完全在设备本地离线完成。

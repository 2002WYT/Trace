IDIOM TRACE · OFFLINE EDITION

HOW TO USE
1. Open "idiom-trace-offline.html" in Chrome, Edge, Firefox, Safari, or another modern browser.
2. Enter a complete four-character idiom, individual characters, pinyin components, or tones.
3. Use 1–4 for tones and 0 or 5 for neutral tone. A sequence such as 3214 fills all four tones.
4. Type initials and finals directly or select them in the quick panel. Type v for ü.
5. Click a clue color to cycle through gray, yellow, and green.
6. Use global initial/final exclusions for components that cannot appear anywhere.
7. Click "Find remaining idioms" to view matching candidates.

NOTES
- The interface supports English, Simplified Chinese, and Traditional Chinese.
- The standalone file follows the browser language and system light or dark appearance.
- The dictionary, pinyin data, interface, and solver are embedded in the HTML file.
- All filtering happens locally. Nothing you enter is uploaded.
- Idiom data is derived from the open-source pwxcoo/chinese-xinhua dataset.

语迹 · 完全离线版

使用方法
1. 使用 Chrome、Edge、Firefox、Safari 或其他现代浏览器打开“idiom-trace-offline.html”。
2. 输入完整四字成语、单个汉字、拼音成分或声调。
3. 声调使用 1～4，0 或 5 代表轻声；输入 3214 之类的序列可一次填写四个声调。
4. 声母和韵母可直接输入，也可从快捷面板选择；可用 v 代替 ü。
5. 点击线索颜色，在灰、黄、绿之间循环。
6. 对确定不会出现的拼音成分使用全局声母、韵母排除。
7. 点击“搜索剩余成语”查看候选结果。

说明
- 界面支持英语、简体中文和繁体中文。
- 独立文件会跟随浏览器语言与系统深浅色外观。
- 完整词库、拼音数据、界面和筛选逻辑均内置在 HTML 文件中。
- 所有筛选都在本地完成，不会上传任何输入。
- 成语数据来源于开源项目 pwxcoo/chinese-xinhua。

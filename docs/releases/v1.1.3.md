# Trace v1.1.3 / 词迹 v1.1.3

Trace 1.1.3 adds complete interface localization, a native-aware dark mode, and a calmer productivity-tool design across Android and the standalone web pages.

## Highlights

### Three interface languages

- English
- Simplified Chinese
- Traditional Chinese

The selected language is stored locally and applies to the home screen, Settings, About, Idiom Trace, and Word Trace. English is the default on non-Chinese systems.

### System, Light, and Dark appearance

- Choose **System**, **Light**, or **Dark** in Settings.
- System mode follows the device appearance.
- Android status and navigation bars and the WebView background match the selected mode.
- Dark mode is applied before the first page paint, and the native transition backdrop stays dark, preventing light flashes when switching tools.

### Practical interface refresh

- Compact forms and familiar productivity-tool structure.
- Neutral surfaces, clear one-pixel boundaries, 6–8 px radii, and system fonts.
- One low-saturation green accent.
- No gradients, glass effects, oversized headings, excessive cards, or heavy shadows.

### Bilingual project presentation

- README files, changelog, release notes, and GitHub Actions labels now place English first and Chinese second.
- Added `GIT_UPLOAD_GUIDE.md` with the complete commit, push, tag, release, APK, checksum, Pages, and repository About workflow.
- Added a tag-triggered and manually runnable GitHub Actions workflow for Android linting and debug APK artifacts.

## Installation

- Requires Android 6.0 (API 23) or later.
- Can update v1.1.2 directly without uninstalling it.
- Existing local preferences are preserved; the new language follows the device until explicitly selected.
- No network or additional system permission was added.

词迹 1.1.3 为 Android 应用和独立网页加入完整界面本地化、与系统栏联动的夜间模式，以及更克制的效率工具风格。

## 主要更新

### 三种界面语言

- 英语
- 简体中文
- 繁体中文

所选语言保存在本地，并应用于首页、设置、关于、语迹和 Word Trace。非中文系统默认使用英语。

### 跟随系统、浅色与深色外观

- 可在设置中选择“跟随系统”“浅色”或“深色”。
- 跟随系统模式会读取设备当前外观。
- Android 状态栏、导航栏和 WebView 背景会与所选模式保持一致。
- 页面首次绘制前即应用深色外观，原生切换底板也会保持深色，避免切换工具时闪过浅色背景。

### 实用型界面改造

- 使用紧凑表单和成熟效率工具常见的信息结构。
- 采用中性色背景、清晰的一像素边界、6～8 像素圆角和系统字体。
- 只保留一种低饱和绿色强调色。
- 移除渐变、玻璃效果、超大标题、过多卡片和厚重阴影。

### 中英双语项目展示

- README、更新日志、发布说明和 GitHub Actions 标签均改为英文在前、中文在后。
- 新增 `GIT_UPLOAD_GUIDE.md`，完整说明提交、推送、标签、Release、APK、校验值、Pages 和仓库 About 的操作流程。
- 新增可由版本标签或手动触发的 GitHub Actions 流程，用于 Android 检查并生成调试 APK 构建产物。

## 安装说明

- 最低支持 Android 6.0（API 23）。
- 可直接覆盖安装 v1.1.2，无需卸载。
- 原有本地设置会保留；新增语言在用户主动选择前跟随设备语言。
- 未新增网络或其他系统权限。
